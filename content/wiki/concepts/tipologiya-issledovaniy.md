# Типология исследований

## Резюме

Единой «главной» типологии исследований не существует — методы развивались эволюционно. Классификация зависит от выбранного критерия. Для UX-контекста наиболее значимы классификации по целям/методам и по типу стратегий.

## Текущее понимание

### По предметной области
Физические, химические, биологические, экономические, социологические и т.п.

**Гуманитарные исследования** (социология, психология, лингвистика, этнография, педагогика, криминология) — особая группа, с которой UX-исследования наиболее родственны. Подробнее: [[specefika-gumanitarnyx-issledovaniy|Специфика гуманитарных исследований]].

### По точности результатов
- Достоверные
- Вероятностные

### По содержанию (используемым практикам дисциплины)
Математические, статистические, экономические, технические, экспертные, социологические, рефлексивные, логические, описательные, измерительные и др.

### По целям и методам
- **Аналитические** — проверка гипотез, выявление причинно-следственных связей, объяснение «почему» происходит явление
- **Эмпирические / экспериментальные** — исследователь активно вмешивается, манипулируя переменной; «золотой стандарт» для установления причинности (пример: клинические испытания)
- **Прогностические** — предсказание будущих событий на основе анализа текущих и исторических данных
- **Оценочные** — определение эффективности программ, продуктов или методов работы

### По типу исследовательских стратегий
- Количественные
- Качественные
- Смешанные
