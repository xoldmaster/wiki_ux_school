# Типология исследований

## Резюме

Единой «главной» типологии исследований не существует — методы развивались эволюционно. Классификация зависит от выбранного критерия. Авторская формулировка курса: типология — это **пространство классификации методов**, то есть многомерный набор независимых осей, а не одна таблица. Для UX-контекста наиболее значимы классификации по целям/методам и по типу стратегий.

## Текущее понимание

### По области применения (предметной области)
Физические, химические, биологические, экономические, социологические и т.п.

> Слайд курса называет эту ось «По области применения» и перечисляет: физические, биологические, социологические, экономические. Альтернативное название «По предметной области» встречается в лекционных текстах.

**Гуманитарные исследования** (социология, психология, лингвистика, этнография, педагогика, криминология) — особая группа, с которой UX-исследования наиболее родственны. Подробнее: [[specefika-gumanitarnyx-issledovaniy|Специфика гуманитарных исследований]].

### По точности результатов
- **Достоверные** — однозначные, детерминированные результаты.
- **Вероятностные** — допускающие статистическую погрешность.

![[Рисунок15.png]]

### По содержанию (используемым практикам дисциплины)
Математические, статистические, экономические, технические, экспертные, социологические, рефлексивные, логические, описательные, измерительные и др.

> Слайд курса сокращает список до четырёх основных практик: **измерительные, экспертные, статистические, рефлексивные** — как наиболее релевантных для учебного контекста.

### По целям и методам

**Аналитические** (= Исследовательские)
- *Фокус:* поиск причинно-следственных связей и факторов риска.
- *Задача:* объяснить, почему происходит то или иное явление; проверка фундаментальных гипотез.

**Эмпирические** (= Экспериментальные)
- *Фокус:* активное вмешательство в систему.
- *Задача:* манипулирование одной переменной для замера её влияния на другие; «золотой стандарт» доказательности.

![[Рисунок16.png]]

**Прогностические**
- *Фокус:* предсказание будущих событий.
- *Задача:* моделирование поведения системы на основе анализа исторических и текущих сырых данных.

**Оценочные**
- *Фокус:* измерение эффективности.
- *Задача:* определение жизнеспособности программ, продуктов, **интерфейсов** или методов работы постфактум.

![[Рисунок17.png]]

### По типу исследовательских стратегий

Ключевое противопоставление — **охват** (количественные) vs **глубина** (качественные).

| Стратегия | Ключевой вопрос | Фокус |
|-----------|-----------------|-------|
| **Количественная** | «Сколько?» | Большие массивы данных; выявляет масштаб проблемы |
| **Качественная** | «Как?» / «Почему?» | Глубокое погружение в контекст и мотивацию |
| **Смешанная (Mixed-methods)** | Оба | Синергия двух подходов для валидации гипотез |
