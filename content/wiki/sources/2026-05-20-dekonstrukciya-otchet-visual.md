## Core Claims

Детальная схема этапа «Подготовка отчёта» в формате Вход → Процесс → Выход:

| Элемент | Содержание |
|---------|------------|
| **Вход** | Готовый анализ данных, найденные закономерности (описание фрагмента объективного мира), цели и задачи исследования |
| **Процесс** | Трансформация: придание объективным знаниям субъективной ценности |
| **Выход** | Такое представление изученной реальности, которое максимально полезно для дальнейшего использования |

Ключевое определение результатов анализа: «описание фрагмента объективного мира» — анализ фиксирует реальность как есть; отчёт делает её полезной для конкретного заказчика.
