## Core Claims

- Цель курса — создание **единого понятийного аппарата** для всех участников лаборатории.
- Без согласованного понимания базовых терминов практическая работа лаборатории будет разваливаться.
- Ключевые синхронизируемые понятия: **Объект**, **Предмет**, **Гипотеза**, **Инсайт**.

## Key Evidence / Details

Схема: четыре термина-стрелки сходятся в прямоугольник «Единый понятийный аппарат». Подпись: «Нам нужно договориться о базовых вещах. Без единого понимания терминов дальнейшая практическая работа лаборатории будет разваливаться.»
