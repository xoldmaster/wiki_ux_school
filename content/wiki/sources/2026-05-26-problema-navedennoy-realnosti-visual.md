## Ключевые утверждения

1. **Необратимость влияния** — сам факт проведения исследования уже необратимо меняет поведение объекта; вернуть «естественное состояние» невозможно.
2. **Инвазивность любого опроса** — любой опрос прерывает нормальный, естественный ход жизни; инвазивность — не исключение, а правило.
3. **Экологичность → валидность** — для обеспечения **валидности** данных необходима максимальная «экологичность» среды исследования.

## Ключевые свидетельства / детали

- Ключевое уточнение по сравнению со слайдом 15: экологичность здесь явно связана с **валидностью данных** — не просто принцип, а условие достоверности результатов.
- Визуальная метафора: небольшой исследователь наблюдает большую прозрачную фигуру-тень — поведение объекта уже «проецируется», трансформировано самим фактом наблюдения.
- Слайд усиливает концептуальную цепочку: присутствие исследователя → нарушение нормы → наведённая реальность → риск невалидных данных.
