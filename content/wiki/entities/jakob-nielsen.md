# Якоб Нильсен

## Резюме

Якоб Нильсен (Jakob Nielsen) — датско-американский исследователь юзабилити, один из основателей современной профессии UX-исследователя. Его книга «Usability Engineering» (1993) формализовала юзабилити как процесс, а не свойство системы. Сооснователь Nielsen Norman Group.

## Текущее понимание

### Ключевые вклады

**«Usability Engineering» (1993):**

1. **Юзабилити — процесс, а не свойство.** «Usability is not a property of a system. Usability is a process.» Это означало: нельзя добавить юзабилити в конце разработки, оно должно быть встроено во весь жизненный цикл.

2. **Стоимость изменений.** Изменения, обнаруженные пользователями после релиза, обходятся примерно в **100 раз дороже**, чем изменения на ранних стадиях проектирования — Нильсен считал это на данных реальных промышленных проектов.

3. **Проклятие знания.** «Знание о системе — это улица с односторонним движением. Невозможно вернуться в состояние, когда не знал ничего.» Разработчик, создавший систему, не может её оценить — это когнитивная особенность человека, а не недостаток разработчика. Это фундаментальное обоснование существования профессии UX-исследователя.

4. **Пять атрибутов юзабилити** (операционализация понятия):

| Атрибут | Оригинал | Определение |
|---|---|---|
| Обучаемость | Learnability | Время до достижения заданного уровня владения |
| Эффективность | Efficiency | Производительность опытного пользователя |
| Запоминаемость | Memorability | Скорость восстановления навыка после перерыва |
| Ошибки | Errors | Частота и тяжесть ошибок пользователей |
| Удовлетворение | Satisfaction | Субъективная оценка взаимодействия |

> Источник: Nielsen, 1993, с. 24–36.

Почему важна **независимость** атрибутов: улучшение по одному может ухудшить другой. Система с плоской кривой обучения (Learnability) может быть неэффективной для эксперта. Нельзя оптимизировать «юзабилити в целом» — нужно выбрать конкретный атрибут для конкретной аудитории.

### Nielsen Norman Group

В 1998 году Нильсен совместно с [[donald-norman|Дональдом Норманом]] основал консалтинговую и обучающую компанию Nielsen Norman Group (NNg). Среди разработок NNg — Skill Mapping Framework, заимствованный матрицей компетенций АЦ.

### Параллель с советской традицией

Сергеев (2008) независимо сформулировал четыре показателя качества интерфейса: соответствие задачам + скорость + ошибки + удовлетворённость. Это та же пятикомпонентная модель Нильсена **минус запоминаемость** — сформулированная в отечественной традиции независимо от западной. Подробнее: [[istoriya-professii-ux|История профессии UX]].
