# Артём Кузнецов

## Резюме

Один из авторов и ведущий лектор курса «Профессия UX-исследователь» (АЦ при Правительстве РФ). Автор ежегодного анализа рынка вакансий UX-исследователей и матрицы компетенций АЦ.

## Текущее понимание

- **Роль в проекте:** один из 4 авторов курса (вместе с Белышкиным А., Логиновой Е., Хахичевым С.); ведущий лектор Модуля 1 («Профессия и индустрия»)
- **Исследования рынка:** анализ вакансий UX-исследователей на hh.ru — 171 вакансия (2024) и 119 вакансий (декабрь 2025); данные легли в основу статистики курса по грейдам, методам и зарплатам
- **Матрица компетенций:** автор «Матрицы компетенций UX-исследователя по грейдам, АЦ при Правительстве РФ», версия 1.0 (2025); основана на данных рынка + NNg Skill Mapping Framework + Userfocus + UXR Skill Matrix
- **Соавторство:** Кузнецов А. и Черных Д. (2026) — совместное исследование (тема не раскрыта в доступных источниках)
